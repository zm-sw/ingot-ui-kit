# Changelog

Every entry is written by the release automation (`scripts/release.mjs`) when
a release lands on `main`. The source of truth is the doc page registry: the
version of a component moves on its page, and the release reads those moves.
Nothing here is written by hand — an entry edited by a person would be the one
thing in the repository nobody can verify.

The kit is installed from a tag; see the README for why a commit SHA is not a
version.
